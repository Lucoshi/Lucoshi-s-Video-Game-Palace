How to Contribute

Mr. Lubberty

Mr. Lubberty: “Welcome, friend. The Glade of Dreams is a rather large place, and preserving everything within it is no small task. If you'd like to help, there are many ways you can contribute.”

🤝 Want to Help Preserve the Glade?

Whether you're a researcher, artist, programmer, archivist, translator, tester, or simply someone with something valuable to contribute, we'd love to hear from you.

✨ I Want to Contribute!

1. 📝 Research & Documentation

Help us uncover, document, and preserve information about the games and their communities.

  • Find missing information.
  • Verify facts and dates.
  • Locate forgotten or obscure sources.
  • Document the history of the games and their communities.
  • Point out information that needs correction.
  • Research developers, publishers, artists, musicians, and other contributors.
  • Research development histories.
  • Locate interviews and developer statements.
  • Document regional releases and versions.
  • Investigate cancelled, unreleased, or prototype material.
  • Compare information between different sources.
  • Help identify unknown or incorrectly identified material.

2. 🌐 Website Development & HTML

Help build, maintain, and improve the Palace's webpages and HTML.

  • Create new webpages.
  • Improve existing webpages.
  • Write and organize HTML.
  • Develop CSS and JavaScript features.
  • Build navigation systems.
  • Create indexes and archive directories.
  • Add interactive features.
  • Create hidden secrets and Easter eggs.
  • Develop ARG elements and puzzles.
  • Create special events and discoveries.
  • Add old-web effects and functionality.
  • Improve accessibility.
  • Improve browser compatibility.
  • Fix bugs in the Palace's own website.
  • Help keep the site's code organized and readable.

3. 🎨 Artwork & Graphics

Help create and prepare artwork and graphics for the archives.

  • Create archive graphics.
  • Create buttons, banners, icons, and backgrounds.
  • Create illustrations.
  • Design page decorations.
  • Recreate missing website graphics.
  • Create diagrams and visual guides.
  • Prepare artwork for different screen sizes.
  • Identify and document the original source of artwork.

4. 🖼️ Image Restoration

Help restore images while preserving their original appearance.

  • Repair damaged images.
  • Improve readability of old scans.
  • Remove accidental damage or corruption.
  • Crop and straighten scans when appropriate.
  • Repair missing portions when restoration is possible.
  • Improve contrast and legibility.
  • Prepare archival copies.
  • Compare restored images against original sources.
  • Preserve the original file alongside restored versions whenever possible.

5. 🧹 Cleaning AI-Generated HTML Artifacts

Help clean up HTML that was generated or assisted by AI.

  • Remove unnecessary or nonsensical code.
  • Fix broken HTML structure.
  • Remove redundant elements and classes.
  • Correct bad formatting.
  • Remove duplicated code.
  • Simplify unnecessarily complicated markup.
  • Fix incorrect nesting.
  • Remove unused elements.
  • Correct incorrect attributes.
  • Make the code easier for humans to understand and maintain.
  • Make AI-assisted code more faithful to the intended design.
“Artificial intelligence has many talents. Writing twelve unnecessary <div> elements is apparently one of them.”

6. 📸 Screenshots & Scans

  • Capture gameplay screenshots.
  • Capture menus and interfaces.
  • Capture old websites.
  • Scan printed material.
  • Scan advertisements and promotional material.
  • Locate missing screenshots.
  • Locate screenshots from older versions of games.
  • Document changes between releases.
  • Provide original-resolution material whenever possible.

7. 🎮 Game Information & Preservation

  • Document gameplay mechanics.
  • Document characters, levels, locations, items, and collectibles.
  • Document secrets and Easter eggs.
  • Document different versions and regional differences.
  • Record release information.
  • Document patches and updates.
  • Preserve information about cancelled or unreleased content.
  • Identify obscure game material.
  • Verify information already present in the archive.

8. 🎵 Music & Audio Preservation

  • Preserve soundtracks.
  • Preserve sound effects.
  • Preserve voice clips.
  • Locate promotional audio and interviews.
  • Preserve radio appearances and old recordings.
  • Document composers and musicians.
  • Identify music used in games and promotional material.
  • Document different soundtrack releases.
  • Locate obscure or difficult-to-find recordings.

9. 🎬 Video Preservation

  • Commercials and trailers.
  • Gameplay footage.
  • Interviews and television appearances.
  • Promotional and developer footage.
  • Behind-the-scenes footage.
  • Web videos and fan-made historical material.
  • Obscure or difficult-to-find footage.
  • Document where and when footage originally appeared.

10. 📚 Manuals, Magazines & Printed Materials

  • Game manuals.
  • Strategy guides.
  • Magazines and newspaper articles.
  • Advertisements and catalogues.
  • Brochures and promotional flyers.
  • Press kits and instruction sheets.
  • Merchandise catalogues.
  • Convention material.
  • Scan and document printed material missing from the archive.

11. 🔍 Fact-Checking & Source Verification

  • Check factual claims.
  • Verify dates.
  • Compare multiple sources.
  • Identify unreliable information.
  • Check quotations.
  • Verify names and credits.
  • Verify release information.
  • Identify incorrect links or references.
  • Find stronger primary sources.
  • Flag claims that require additional evidence.
  • Correct mistakes found in existing pages.

12. 🌍 Translation & Localization

  • Translate archive pages.
  • Translate historical documents.
  • Translate manuals and advertisements.
  • Translate interviews.
  • Translate captions and descriptions.
  • Document regional terminology.
  • Compare localized versions of games.
  • Document localization differences.
  • Proofread existing translations.
  • Preserve information that exists only in another language.

13. 💾 File Organization & Archival Work

  • Organize folders.
  • Rename files consistently.
  • Identify duplicate files.
  • Separate original and restored files.
  • Maintain backups.
  • Organize archival versions.
  • Check file integrity.
  • Track where files came from.
  • Maintain archival copies.
  • Establish consistent file-naming systems.
  • Organize large collections of material.

14. 🕹️ Testing & Usability

  • Test webpages and links.
  • Test interactive features.
  • Test hidden features and Easter eggs.
  • Test ARG elements.
  • Test pages on different browsers and screen sizes.
  • Identify confusing navigation.
  • Identify accessibility problems.
  • Report visual glitches.
  • Report usability problems.
  • Make sure visitors can find the information they need.

15. ✍️ Writing & Proofreading

  • Write archive descriptions.
  • Write historical articles.
  • Improve existing articles.
  • Proofread pages.
  • Correct spelling and grammar.
  • Improve clarity.
  • Rewrite confusing passages.
  • Maintain consistent terminology.
  • Write captions.
  • Write explanations for archival material.
  • Make technical information easier to understand.

16. 🔧 Website Restoration

Help restore old, lost, damaged, or incomplete websites.

  • Recover missing webpages.
  • Reconstruct broken pages.
  • Restore old HTML.
  • Restore original navigation.
  • Recreate missing graphics.
  • Repair broken links.
  • Reconstruct missing layouts.
  • Restore archived website content.
  • Preserve different versions of a website.
  • Compare old versions of webpages.
  • Recreate websites from screenshots or surviving files.
  • Preserve original appearance and functionality as faithfully as possible.
“Restoration is not about making an old website look modern. Sometimes the blinking text and tiny buttons are part of the history.”

17. 🗂️ Metadata, Cataloguing & Tagging

  • Add metadata.
  • Identify dates, creators, and sources.
  • Tag files.
  • Categorize material.
  • Create indexes.
  • Maintain databases and lists.
  • Record version and regional information.
  • Link related archival material.
  • Identify relationships between sources.

18. 💡 Finding Missing Material

  • Search for lost webpages.
  • Find missing screenshots.
  • Find old promotional material.
  • Locate forgotten interviews.
  • Find old videos.
  • Locate missing manuals.
  • Find magazine articles.
  • Search old fan sites and web archives.
  • Contact collectors and preservation communities.
  • Identify material known to exist but not yet archived.
“Sometimes the most valuable contribution is simply knowing where to look.”

19. 🐛 Finding & Reporting Website Errors

  • Report broken links.
  • Report missing images.
  • Report incorrect information.
  • Report HTML, CSS, and JavaScript errors.
  • Report broken navigation.
  • Report formatting problems.
  • Report missing pages.
  • Report browser compatibility issues.
  • Report accessibility problems.
  • Report broken Easter eggs.
  • Report broken ARG elements.
  • Report anything that doesn't work as intended.
